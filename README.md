# Neighborhood Barbecue

One block, one barbecue, two eras. Drag the divider between a 1957 cookout and a greener someday where sheep, goats and bison keep the grass, then head to the City Barbecue Festival in the Beautiful Hensel Thicket, where today's lawn crew drowns out the band.

A single standalone HTML page with everything embedded. Live at https://songbird-soundscape.github.io/neighborhood-barbecue/
